# Guess the Number 🎯

This is a simple number guessing game that I made with Python.

The computer chooses a random number between 1 and 100, and the player has to guess it.

## How the Game Works

- The computer picks a random number from 1 to 100.
- You have 10 attempts to guess the number.
- If your guess is too low, the game tells you to try a higher number.
- If your guess is too high, the game tells you to try a lower number.
- If you guess correctly, you win!
- If you use all 10 attempts, the game shows you the correct number.
- At the end, you can choose to play again.

## What I Used

- Python
- `random.randint()`
- Functions
- `while` loops
- `if`, `elif`, `else`
- `try` and `except`
- `input()` and `print()`

## How to Run

1. Make sure Python is installed.
2. Download the project.
3. Open the terminal in the project folder.
4. Run the game:

```bash
python main.py
```
